⬇ Collection 다운로드 Postman 설치
Postman v10 이상에서 사용하세요. Collection v2.1 형식으로 생성되어 있습니다.

Import 방법

  1. 위 Collection 다운로드 버튼으로 jangingmall-api.postman_collection.json 저장
  2. Postman 실행 → 좌측 상단 Import 버튼 클릭
  3. 다운로드한 파일을 드래그하거나 files로 선택
  4. Import 완료 후 Collections 패널에서 장인몰 (미담) API 확인
  5. 인증이 필요한 요청: Collection 루트 → Variables 탭 → accessToken 값 입력

인증 설정

  1. POST /api/member/login 요청 실행
  2. 응답의 data.accessToken 값 복사
  3. Collection → Variables → accessToken Current Value에 붙여넣기
  4. 이후 모든 인증 필요 요청에 Authorization: Bearer {{accessToken}} 자동 적용
