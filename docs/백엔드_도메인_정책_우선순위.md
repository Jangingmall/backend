## 1. 인증 (Auth) — P0

### 엔드포인트 범위
- `POST /auth/signup`
- `POST /auth/login`
- `POST /auth/logout`
- `POST /auth/token/refresh`
- `POST /auth/email/verify` — 6자리 코드 발송
- `POST /auth/email/verify/confirm`
- `GET /oauth2/authorize/{provider}` — provider: naver, kakao
- `GET /oauth2/callback/{provider}`

### 정책
- 계정 식별자: 이메일 (화면 레이블 「아이디」이지만 실제 값은 이메일)
- 소셜: 네이버·카카오만 (구글 v1.0 삭제 확정)
- 비밀번호: 8~20자, 영문+숫자+특수문자 필수 (**주의: BE 현재 6~22자와 상이 — FE 합의 필요**)
- 로그인 5회 실패 → 10분 계정 잠금
- 이메일 인증 코드: 유효 10분, 1회용, 재발송 60초 쿨다운, 시간당 5회 상한, 5회 오입력 시 코드 폐기 후 재발송 요구
- 이메일 변경 시 인증 상태 해제 → 재인증 필요
- JWT: Access Token + Refresh Token (Redis 저장, HttpOnly Cookie)
- 비밀번호 재설정 토큰: 유효 30분, 1회용, 완료 시 전 기기 세션 만료
- 소셜 이메일 미제공 시: 이메일 필수 입력 + 인증. 동일 이메일 기존 계정 존재 시 신규 생성 대신 소셜 연동
- 약관 동의 버전 기록: 동의 시점 버전을 회원별 저장
- 약관 5종: 이용약관(필수) / 개인정보처리방침(필수) / 개인정보 수집·이용(필수) / 만 14세 이상(필수) / 마케팅 수신(선택)
- `return_to` 파라미터 저장 후 로그인 성공 시 복귀
- 가입 완료 시 자동 로그인 상태 전환

## 2. 회원 (Member) — P0

### 정책
- 이메일 변경 불가 (계정 식별자 고정)
- 이름·전화번호 수정 가능
- 소셜 전용 계정: 비밀번호 없음 → 비밀번호 변경 항목 응답에서 제외
- 비밀번호 변경: 현재 비밀번호 확인 필수, 직전 비밀번호와 동일 불가, 완료 시 다른 기기 세션 전체 만료

### 회원 탈퇴
- 탈퇴 차단 조건: 진행 중 주문 또는 클레임 존재 시 불가
- 탈퇴 후 90일 보관 → 계정 파기
- 거래 기록(계약·대금결제): 전자상거래법상 5년 익명화 보관 (90일 이후에도 유지)
- 탈퇴 즉시 로그아웃 처리

### 배송지
- 최대 10건 (v1.1에서 5건 → 10건으로 변경)
- 기본 배송지 1개만 지정 가능
- 기본 배송지 삭제: 다른 배송지를 기본으로 지정 후에만 삭제 가능

### 결제 수단 저장 (MY-8 — P2)
- PG 빌링키 계약 선행 필요
- 빌링키 미계약 시: 내 결제 수단 탭 숨김, 매 결제마다 카드 직접 입력

## 3. 상품 (Product) — P0

### 카테고리
- 대분류 7개: 키친·다이닝 / 홈·인테리어 / 패션·악세사리 / 데스크·문구 / 패브릭·생활 / 아트·컬렉션 / 식품·전통주
- 소분류 56개
- 노출 규칙: 대분류 0점 숨김 / 소분류 0~4점 숨김, 5점 이상 노출, 20점 초과 분할 검토
- 식품·전통주: MVP OFF (식품위생법 선행 조건 미충족)

### 상품 배지 우선순위
한정 수량 > 신작 > 인기 — 조건 여러 개 충족 시 대표 1개만 노출

### 판매 방식 3종
- 바로 배송
- 한정 수량
- 주문제작 (제작 기간 필수)

### 옵션 정책
- 필수 옵션: 최대 3축 (SP-3 확정 9/16)
- 선택 옵션: 선물 포장 등 가산 금액 부가 옵션 1개
- 입력 옵션: 각인 문구 등 텍스트
- 옵션 1건 = SKU 1건
- 판매 이력 있는 옵션값: 삭제 불가 → 품절 처리만 가능

### 재고
- 주문제작: 재고 대신 「월 제작 가능 수량」
- 재고 알림 기준: n 이하 시 판매자 대시보드 경고 (n 미정)

### 상품 정보 제공 고시 (전자상거래법 필수 7항목)
1. 품명·모델명
2. 크기·중량
3. 재질
4. 구성품
5. 제조사·제조국
6. A/S 책임자·연락처
7. 품질보증기준

### 상품 상태 전환
- 판매중 ↔ 숨김 (URL 직접 접근도 차단)
- 품절: 재고 0 자동 또는 수동 강제
- 삭제: 주문 이력 있는 상품 삭제 불가 → 숨김만 가능

## 4. AI 상세페이지 콘텐츠 — P0

### 콘텐츠 승인 흐름
1. AI 생성 완료 → 상태: `DRAFT`
2. 장인이 체크리스트 2개 **모두** 통과해야 승인 가능
   - `factCheckConfirmed` — 사실확인 체크
   - `photoMatchConfirmed` — 사진일치 체크
3. 승인 시 상태: `APPROVED` / 반려 시 상태: `REJECTED` (사유 필수)
4. `POST /api/content/products/{productId}/publish` 호출 시 상태: `PUBLISHED` → 상품 노출

### 정책
- `PUBLISHED` 상태가 되기 전까지 소비자 노출 불가 (설계 제약 C3)
- 생성 횟수 제한: 상품당 1일 n회 (n 미정 — 비용 통제)
- 게시 후 상세 내용 수정 시 게시 자동 해제 → 재확인 필요
- 게시자·일시 감사 로그 기록

### 금지 표현 (저장 차단 + 위치 표시)
- 가격 직접 언급
- 과장 표현
- 의학적 효능 표현 (표시광고법 리스크)

### AI 참조 범위
- 이야기 소재(④섹션)만 읽음 — 기본 정보(①~③)는 상품 데이터로 사용

### 입력 원문 대조
- 각 섹션이 어느 입력 항목에서 나왔는지 표시
- 입력에 없는 내용은 「확인 필요」 표시

## 5. 장바구니 (Cart) — P0

### 정책
- 최대 50종
- 초과 시: 가장 오래된 항목을 찜으로 이동
- 비회원(게스트) 장바구니 허용 — 쿠키의 `guestCartId`로 식별
- 로그인 시 `POST /api/payments/cart/merge` 로 게스트 장바구니를 회원 장바구니에 병합 (동일 상품+옵션 조합은 수량 합산)
- 주문 생성(`POST /api/payments/orders`)부터 로그인 필수
- 장바구니 진입 시 가격·재고·판매 상태 재조회 (유효성 검증)
- 배송비: 장인 단위 계산 (합산이 아닌 max)
- 묶음배송: 같은 장인 2점째부터 배송비 0
- 주문제작 포함 시 전체 상품 함께 배송 (분리 배송 없음)
- 삭제 되돌리기: 5초 내 「장바구니에 다시 넣기」

## 6. 주문·결제 (Order/Payment) — P0

### 결제 수단 4종 (FigJam 0907 확정)
1. 실시간 계좌이체
2. 무통장 입금
3. 간편결제 (토스페이먼츠)
4. 신용·체크카드

**PG**: 토스페이먼츠

### 무통장 입금 특이사항
- PG 팝업 없이 즉시 주문 생성 → 상태: 「입금 확인 중」
- 주문 목록/상세에 「입금 확인 중」 상태 및 「입금 정보 확인」 버튼 필요

### 결제 안전 정책
- PG 승인 결과를 서버에서 재검증 후 주문 확정 (클라이언트 응답만으로 확정 금지)
- 중복 결제 방지: 주문번호 단위 멱등 처리, 결제 진행 중 버튼 비활성
- 결제 직전 재고 재검증: 부족분을 행 단위로 고지, 수량 보정 또는 제외

### 주문번호 형식
`ORD{YYYYMMDD}{NNN}` 형식 (예: `ORD20260825001`) — 응답 값 복사 가능 필요  
**주의: 화면 정의서의 `MD-YYYYMMDD-NNNNNN` 과 API 명세의 `ORD20260825001` 불일치 — 확정 전 FE/BE 합의 필요**

### 주문 상태 6종
입금 확인 중 / 상품 준비 및 제작 중 / 배송 중 / 배송 완료 / 주문 취소 / 환불

### 구매 확정
- 배송 완료 7일 후 자동 확정 (스케줄러)
- 수동 확정: 확인 모달 후 확정 → 정산 대상 전환

### 할인 코드·적립금·쿠폰
UI 슬롯만 두고 발급·소멸 정책 미확정 → MVP 비활성 처리

## 7. 취소·반품·교환 (Claim) — P0~P1

### 취소 정책
- 주문제작 착수 후 취소 불가 (착수 기준 상태 확정 필요)
- 배송 시작 후 취소 불가
- 부분 취소 시 배송비 재계산 반영

### 반품·교환
- 신청 기한: 수령 후 7일 (임시값 — 확정 필요)
- 귀책 판정 3종: 판매자 귀책 / 구매자 귀책 / 협의 (판정 기준 문서 필요 — R3)
- 반품 배송비 부담: 귀책에 따라 상이 (정책 미확정)

### 클레임 상태 흐름
접수 → 검토 중 → 승인/반려 → 회수 → 완료

## 8. 후기 (Review) — P1~P2

### 정책
- 작성 자격: 구매 확정 건에 한해 가능
- 별점: 1~5 정수 (0.5 단위 없음)
- 본문: 10~2000자
- 사진: 최대 5장, 장당 10MB, jpg/png/webp
- 수정: 작성 후 30일 이내
- 삭제: 언제든 가능
- 작성 후 상품 상세에 즉시 반영
- 작성 시 장인에게 알림 발송
