## 배포 구성 (prod)

```
Client
  └─ HTTPS → AWS ALB (TLS 종료) → EC2 (nginx) → Spring Boot jar (Tomcat 내장)
```

- SSL/TLS: ALB에서 종료. nginx ↔ Spring Boot 구간은 HTTP (내부 통신)
- nginx는 리버스 프록시 역할만 수행

### nginx 핵심 설정

```nginx
proxy_pass         http://127.0.0.1:8080;
proxy_http_version 1.1;
proxy_set_header   Connection "";          # keep-alive (HTTP/1.1 기본)
proxy_set_header   Host              $host;
proxy_set_header   X-Real-IP         $remote_addr;
proxy_set_header   X-Forwarded-For   $proxy_add_x_forwarded_for;
proxy_set_header   X-Forwarded-Proto $scheme;

# SSE 필수 — 미설정 시 이벤트가 버퍼링되어 클라이언트에 즉시 전달되지 않음
proxy_buffering    off;
proxy_cache        off;

# heartbeat 간격(30s)보다 충분히 길게 — 미달 시 idle timeout으로 SSE 연결 강제 종료
proxy_read_timeout    3600s;
proxy_send_timeout    3600s;
proxy_connect_timeout 60s;
```

### Spring Boot (application.yml) 핵심 설정

```yaml
spring:
  mvc:
    async:
      # -1: 무제한. 미설정 시 Tomcat 기본값(30s)이 적용되어 SSE 연결이 30s 후 종료됨
      request-timeout: -1
  threads:
    virtual:
      enabled: true   # 가상 스레드 — 블로킹 I/O 다수인 SSE/알림 처리에 유리

server:
  tomcat:
    connection-timeout: 20000   # 초기 연결 타임아웃(ms). SSE 연결 자체와 무관
```

### AWS ALB

| 항목 | 값 | 이유 |
|---|---|---|
| Idle timeout | 3600s | heartbeat(30s) 대비 충분한 여유. 미달 시 SSE 연결 강제 종료 |
| 리스너 | HTTPS:443 → HTTP:80 (EC2 nginx) | TLS 종료를 ALB에서 처리 |

### SSE 타임아웃 체인 (heartbeat = 30s)

| 레이어 | 설정값 | 비고 |
|---|---|---|
| ALB idle timeout | 3600s | heartbeat 120배 여유 |
| nginx proxy_read_timeout | 3600s | ALB와 동일 수준 |
| Spring mvc.async.request-timeout | -1 | 무제한 (필수) |
| SseEmitter 생성자 timeout | -1L | 무제한 (필수) |
| Redis sse:online TTL | 90s | heartbeat 3배, 매 heartbeat마다 갱신 |

> SSL은 ALB에서 TLS 종료하므로 idle timeout 설정 없음.
