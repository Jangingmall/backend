# 시연자 전달사항

시연 화면은 **실제 API로 나오는 곳**과 **시연 데이터(MSW)로 나오는 곳**이 섞여 있다. 우리 이미지·상세 소개가 보이는 곳 위주로 동선을 잡는다.

## 먼저 확인 (시연 전)

1. STG 에 V16~V23 이 적용됐는지 확인한다. 이미지 주소는 `develop` 의 raw 주소라 머지 후 약 5분 뒤 열린다.
2. 링크 점검: `python3 scripts/demo-products/check_links.py` → 이상 0개여야 한다.
3. 상세 페이지는 캐시가 있을 수 있다. 보이지 않으면 5분 뒤 새로고침한다.

## 시연 동선 (이 순서로 누른다)

| 순서 | 화면 | 누를 곳 | 보여 줄 것 |
|---|---|---|---|
| 1 | 홈 | **신상품** 4칸 | 청사초롱 벽등·매화 은반지·모시 접선·옻칠 흑선 |
| 2 | 홈 | **베스트** 5칸(판매순) | 청자 분청 찻잔·옻칠 쟁반·옥 매듭 반지·한지 무드등·왕골 부채. 첫 카드 → 상세에 사진 3장·섹션 7개 |
| 3 | 홈 | **기획전**(찜순 4칸, 또는 `GET /api/exhibitions`) | 대나무 조명·백잔·자연염 러너·산수화 부채. 기획전 배너 2장 |
| 4 | 전체 상품 | 상단 메뉴 **전체 상품**(기본 인기순) | 첫 줄이 합죽선·청자 찻잔·분청 찻잔·노리개·모란도 액자·한지 조명·모시 스카프·나전 명함집 순(고정) |
| 5 | 합죽선 상세 | 갤러리 썸네일 → 스크롤 | 본문 사진 9장·섹션 9개 |
| 6 | 청자 운학문 찻잔 상세 | 두 번째 카드 | 갤러리와 본문 8섹션(사진 8장 세트) |
| 7 | 판매자 | 상품 등록 → 사진 1~8장 → 생성하기 | 업로드용 8장 세트(`photoreal/seller/`). 초안 단계에서 멈추면 `docs/seller-ai-draft-ready-flow.md` 참고 |
| 8 | 카테고리 | 카테고리 → 소분류 | 이름에 숫자 없음, 설명은 장인 소개체, 모든 상품에 본문과 특징 카드 |
| 9 | 장바구니·주문서 | 합죽선 담기 → 주문서 | 주문서 이미지가 실사 |

## 누르지 않는 곳

- 홈 **선물·장인관**: FE 시연 데이터와 FE 이미지다. 보여 주기만 한다.
- 프론트가 아직 MSW 로 부르는 화면(베스트·기획전을 실제 API 로 바꾸기 전)은 위 상품이 나오지 않을 수 있다. 바꾼 뒤에 시연한다.
- **옵션 선택**: 실제 API 상세는 옵션을 내려주지 않는다.
- **별점·후기**: 시드 상품은 후기가 없어 "평점 미제공"으로 나온다.

## 말할 때 유의할 점

- 상품 이미지는 AI 로 만든 시연용 이미지다(우하단 ✦ 표시). 실제 장인 작품 사진이라고 설명하지 않는다.
- 이름·설명은 시연용으로 쓴 글이며 실제 인물·수상·인증을 뜻하지 않는다.
