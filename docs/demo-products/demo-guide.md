# 시연자 전달사항

시연 화면은 **실제 API로 나오는 곳**과 **시연 데이터(MSW)로 나오는 곳**이 섞여 있다. 우리 이미지·상세 소개가 보이는 곳 위주로 동선을 잡는다.

## 먼저 확인 (시연 전)

1. STG 에 V16~V23 이 적용됐는지 확인한다. 이미지 주소는 `develop` 의 raw 주소라 머지 후 약 5분 뒤 열린다.
2. 링크 점검: `python3 scripts/demo-products/check_links.py` → 이상 0개여야 한다.
3. 상세 페이지는 캐시가 있을 수 있다. 보이지 않으면 5분 뒤 새로고침한다.

## 시연 동선 (이 순서로 누른다)

| 순서 | 화면 | 누를 곳 | 보여 줄 것 |
|---|---|---|---|
| 1 | 홈 | **신상품** 영역의 첫 번째 카드 **전주 합죽선 · 매화선** | 실사 대표 이미지, 최신 등록 순서 |
| 2 | 합죽선 상세 | 갤러리 썸네일 3장을 차례로 클릭 → 아래로 스크롤 | 본문 소개(사진 9장·섹션 9개): 제작 이야기, 표면과 문양, 색채, 사용 장면, 부채의 각도, 관리 안내 |
| 3 | 전체 상품 | 상단 메뉴 **전체 상품**(최신순) | 첫 줄이 합죽선·청자 찻잔·분청 찻잔·노리개 순 |
| 4 | 청자 운학문 찻잔 상세 | 두 번째 카드 | 갤러리 3장 + 본문 이미지 3장, 소재와 결·쓰임·관리 안내 |
| 5 | 판매자 | 판매자 상품 등록 → 사진 **1~8장** 업로드 → 생성하기 | 판매자 업로드용 8장 세트 사용(`docs/demo-products/photoreal/seller/`, 상품당 8장) |
| 6 | 카테고리 | 카테고리 메뉴 → 소분류 | 상품 이름에 숫자가 없고 설명이 장인 소개체로 나온다 |
| 7 | 장바구니·주문서 | 합죽선을 담고 주문서로 | 주문서 이미지가 실사로 나온다(회색 체크무늬 아님) |

## 누르지 않는 곳 (우리 데이터가 아니다)

- **홈 베스트·기획전·선물·장인관**: FE 시연 데이터와 FE 이미지다. 보여 주기만 하고 상품을 눌러 흐름을 이어 가지 않는다.
- **소재·공예·선물 포장 필터, 판매량순·찜 많은 순**: 켜면 결과 전체가 시연 카탈로그로 바뀐다. 쓰지 않는다.
- **옵션 선택(크기·대나무·색상·포장)**: 실제 API 상세는 옵션을 내려주지 않는다. 시연 대본에서 언급하지 않는다.
- **별점·후기**: 시드 상품은 후기가 없어 "평점 미제공"으로 나온다.

## 말할 때 유의할 점

- 상품 이미지는 AI 로 만든 시연용 이미지다(우하단 ✦ 표시). 실제 장인 작품 사진이라고 설명하지 않는다.
- 이름·설명은 시연용으로 쓴 글이며 실제 인물·수상·인증을 뜻하지 않는다.
