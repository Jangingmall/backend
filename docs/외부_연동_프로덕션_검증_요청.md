# 외부 연동 프로덕션 검증 요청

기준일: 2026-09-09
대상: 회원 소셜 로그인, 이미지 S3 업로드, 토스페이먼츠, 스마트택배

## 인프라 설정 요청

| 연동 | 운영 환경 설정 | 백엔드 환경변수 | 확인 방법 |
| --- | --- | --- | --- |
| 카카오 OAuth | 카카오 개발자 콘솔에 `https://{API_HOST}/login/oauth2/code/kakao` 등록 | `KAKAO_CLIENT_ID`, `KAKAO_CLIENT_SECRET` | 카카오 로그인 후 회원 생성 또는 기존 회원 로그인, 프론트 콜백 이동 |
| 구글 OAuth | Google Cloud Console에 `https://{API_HOST}/login/oauth2/code/google` 등록 | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | 구글 로그인 후 이메일 검증된 계정으로 로그인 |
| S3 이미지 | 비공개 버킷, CORS `PUT` 허용, EC2/ECS 역할에 `PutObject`, `HeadObject`, `DeleteObject` 부여 | `IMAGE_UPLOAD_BUCKET`, `AWS_REGION`, 선택 `IMAGE_STORAGE_KEY_PREFIX` | Presigned URL 발급 후 WebP 업로드, HeadObject 검증 성공 |
| 토스페이먼츠 | 테스트 키로 먼저 승인·취소 검증 후 라이브 키 전환 | `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`, 선택 `TOSS_API_BASE_URL` | 주문 생성 → 결제 준비 → 토스 승인 → 백엔드 승인 → 취소 |
| 스마트택배 | API Key 발급, 출발지 IP allowlist 필요 여부 확인 및 NAT 고정 IP 등록 | `SWEET_TRACKER_API_KEY`, 선택 `SWEET_TRACKER_API_BASE_URL` | 발송 등록된 주문의 운송장으로 `GET /api/payments/orders/{orderId}/delivery` 호출 |

Parameter Store String 값을 컨테이너 환경변수로 주입한다. 이미지 CDN 주소는 `/{env}/backend/image-base-url` → `IMAGE_BASE_URL`, AI 런타임 주소는 `/{env}/backend/ai-endpoint` → `AI_BASE_URL`로 매핑한다. DB에는 두 주소가 아닌 S3 `objectKey`만 저장한다.

## 운영 배포 전 DB 반영

- `order_delivery`: 주문별 택배사 코드, 송장 번호, 최신 배송 상태
- `order_return`: 주문당 반품·교환 1건, 사유, 회수지, 사진 object key, 상태 및 낙관적 락
- `image_upload`: 업로드 소유자, 목적, 원본 해상도, variant object key, 소비 여부, 만료 시각

ERD는 [장인몰_ERD_물리설계.csv](장인몰_ERD_물리설계.csv)에 반영돼 있다. 운영 프로필은 Hibernate 검증 모드이므로 배포 전에 PostgreSQL 마이그레이션을 적용해야 한다.

## 배포 뒤 검증 순서

1. 운영 도메인에서 카카오·구글 OAuth 콜백을 각각 1회 수행한다.
2. 로그인 토큰으로 `POST /api/images/presigned-url`를 호출하고, 반환된 모든 variant URL에 `Content-Type: image/webp`로 PUT 한다.
3. 관리 서비스 계정으로 `POST /api/internal/images/verify`를 호출해 소유자와 S3 객체 존재를 확인한다.
4. 토스 테스트 결제로 주문 생성, 결제 준비, 승인, 취소를 순서대로 수행한다. 승인 요청 금액은 주문 금액과 동일해야 한다.
5. 장인 주문 처리 기능에서 배송 정보를 등록한 뒤, 구매자 토큰으로 배송 조회를 호출한다. 조회는 사용자 요청 시 스마트택배 API를 호출한다.
6. 불량 반품은 사진을 포함해 접수하고, 동일 주문의 재접수가 `409 CONFLICT`인지 확인한다.

## 현재 구현의 연결 지점

- 이미지 업로드: `POST /api/images/presigned-url`, `DELETE /api/images/{imageId}`, `POST /api/internal/images/verify`
- 결제: `POST /api/payments/orders`, `POST /api/payments`, `POST /api/payments/confirm`, `POST /api/payments/{paymentId}/cancel`
- 배송·반품: `GET /api/payments/orders/{orderId}/delivery`, `POST /api/payments/returns`

스마트택배 조회는 API Key, 택배사 코드, 송장 번호가 모두 있어야 실제 호출된다. 배송 정보 등록은 장인 주문 처리 기능이 `DeliveryService.registerDispatch`를 호출해 연결하도록 분리돼 있다.
