# 시연 행동지침 (PD · PM 전달용)

소비자 라이브 시연을 **클릭 순서와 멘트 그대로** 따라 하면 되도록 정리했다. 기준은 `docs/테스트 시나리오.md`의
**Flow 1 — 목적 분명: 검색·필터 직접 구매**(홈 → 카테고리 → 상품 → 상세 → 구매하기 → 주문서 → 결제하기)이다.
**시연은 "결제하기"를 눌러 토스 결제창이 열리는 데까지**만 진행한다(실제 결제 승인은 하지 않는다).

> 이 문서는 코드·데이터·테스트로 확인한 내용이다. 배포된 STG 화면에서 직접 클릭해 본 결과가 아니므로, 아래 **0. 사전 점검**을
> 시연 30분 전에 한 번 해 본다.

---

## 0. 사전 점검 (시연 30분 전, 5분)

| # | 확인 | 방법 | 기대 결과 | 안 되면 |
|---|---|---|---|---|
| 1 | 최신 배포 반영 | 홈 "신상품" 첫 칸을 본다 | **전주 합죽선 · 매화선**이 맨 앞이다 | 배포(CD)가 끝났는지 BE 담당에게 확인 |
| 2 | 이미지 링크 | 브라우저 새 탭에 `https://raw.githubusercontent.com/Jangingmall/backend/develop/docs/seed-images/sub-01.webp` | 그림이 열린다 | `develop` 머지 여부 확인, 안 열리면 BE 담당 호출 |
| 3 | FE 데이터 모드 | FE 담당에게 "실제 API 모드(`NEXT_PUBLIC_DATA_MODE=api`)로 배포됐는지" 확인 | 실제 API 모드 | 목업 모드면 BE 데이터가 안 보인다 |
| 4 | 로그인 | 시연 계정(`stgUser@midam.store`, 비밀번호는 담당자가 따로 전달)으로 로그인 | 로그인 성공 | 비밀번호 재확인. 같은 계정으로 여러 곳에서 동시에 로그인해도 끊기지 않는다 |
| 5 | 결제창 | 아래 5·6단계까지 한 번 눌러 본다 | 토스 결제창이 열린다 | 결제 키 설정은 BE/인프라 담당 확인 |

**준비물**: 크롬 최신, 팝업 허용(토스 결제창이 새 창으로 열린다), 화면 확대 100%.

## 1. 시연 순서 (이 순서 그대로)

### 1막. 홈 — 이 서비스가 무엇인지 (약 1분)

| 단계 | 클릭 / 행동 | 말할 문장 | 화면에서 보이는 것 |
|---|---|---|---|
| 1 | 홈 화면을 연다. 스크롤은 하지 않고 맨 위를 보여 준다 | "담은 몰은 전통 공예 장인의 작품을 직접 만나는 마켓입니다." | 히어로 배너 |
| 2 | **선물** 섹션으로 스크롤한다 | "선물할 때 막막하셨다면, 상황으로 고르실 수 있어요." | 왼쪽 테마 버튼 8개, 오른쪽 상품 3개 |
| 3 | 테마 버튼 **돌 · 환갑**을 누른다 | "부모님 환갑 선물이면 합죽선과 청자 찻잔이 먼저 보입니다." | 상품 3개가 바뀐다(전주 합죽선 · 매화선, 청자 운학문 찻잔, 하늘빛 한산모시 스카프) |
| 4 | 테마 버튼 **집들이 · 이사**를 누른다 | "집들이라면 분청 찻잔, 자수 액자, 한지 조명이 나옵니다." | 분청 귀얄 찻잔, 수자수 모란도 액자, 한지 무드 조명 |
| 5 | **장인** 영역으로 스크롤한다 (캐러셀 좌우 화살표 한 번) | "작품 뒤에는 20~30년 경력의 장인이 있습니다." | 장인 카드(구혜자 침선공방 · 예당한복 소품 · 소품쟁이 자수표구 …) 6명 |
| 6 | **신상품** 섹션으로 스크롤한다 | "새로 들어온 작품입니다." | 전주 합죽선 · 매화선 / 청자 운학문 찻잔 / 분청 귀얄 찻잔 / 홍매 삼작 노리개 |

> 장인 카드의 "우수 장인"·경력·한 줄 문구는 **시연용 가짜 값**이다. "공식 인증"이라고 말하지 않는다.

### 2막. 카테고리에서 상품으로 (약 1분)

| 단계 | 클릭 / 행동 | 말할 문장 | 화면에서 보이는 것 |
|---|---|---|---|
| 7 | 상단 메뉴 **전체 상품**을 누른다 | "전체 작품을 카테고리로 둘러볼게요." | 상품 목록 + 왼쪽 필터 |
| 8 | 왼쪽 필터 **분류**에서 대분류 **아무거나** 누른다 (권장: **패션·액세서리**) | "분류는 일곱 가지입니다. 패션·액세서리를 볼게요." | 해당 대분류의 상품 목록, 위쪽 경로(홈 › 전체 카테고리 › 패션·액세서리) |
| 9 | 같은 필터의 소분류 **부채**를 누른다 | "부채만 보면 합죽선이 있습니다." | 부채 소분류 상품들 |
| 10 | 정렬을 **최신순**으로 바꾼다 (이미 최신순이면 생략) | "최근 등록순으로 볼게요." | 전주 합죽선 · 매화선이 앞쪽에 있다 |
| 11 | 상품 카드 **전주 합죽선 · 매화선**을 클릭한다 | "이 작품을 열어 볼게요." | 상품 상세 화면 |

> 다른 대분류를 눌러도 시연은 된다. 키친·다이닝, 홈·인테리어, 패브릭·생활, 데스크·문구, 아트·컬렉션, 식품·전통주 모두 상품이 있다.
> 소분류에 상품이 없으면 "이 카테고리의 상품은 준비되는 대로 …" 안내가 나온다 — 그때는 대분류로 돌아가 다른 소분류를 누른다.

### 3막. 상품 상세 (약 1분)

| 단계 | 클릭 / 행동 | 말할 문장 | 화면에서 보이는 것 |
|---|---|---|---|
| 12 | 상세 화면 위쪽 이미지를 본다. 이미지 **다음 / 아래 썸네일**을 눌러 4장을 넘겨 본다 | "대표 사진, 소재 무늬, 만드는 법까지 사진으로 확인하실 수 있어요." | 갤러리 4장 (대표 · 소재 무늬 확대 · 합죽선 확대 · 선면 매화) |
| 13 | 상품명·가격을 짚는다 | "전주 합죽선 매화선, 15만 원입니다." | 150,000원, 제작 기간 14일 |
| 14 | 아래로 스크롤해 상품 소개를 읽는다 | "담양 왕대를 3년 건조해 손으로 깎고, 한지를 겹겹이 붙였습니다. 매화를 한 획씩 직접 그려 같은 부채가 하나도 없어요." | 상품 소개 문구 |

> 다른 상품으로 시연해도 된다. 상품마다 상세 이미지가 3장(대표 + 소재·무늬 확대 + 작업대 위 장면과 색 견본 점) 나온다. 이미지에는 글자가 없고 이름·소개·색상은 화면의 텍스트로 보인다.

### 4막. 구매에서 결제창까지 (약 2분)

| 단계 | 클릭 / 행동 | 말할 문장 | 화면에서 보이는 것 |
|---|---|---|---|
| 15 | **구매하기**를 누른다 (옵션이 없는 상품이라 바로 눌러도 된다) | "마음에 들면 바로 구매할 수 있습니다." | 로그인 상태면 주문서로 이동. 로그아웃 상태면 로그인 화면 |
| 16 | (로그인 화면이 나오면) 이메일·비밀번호를 입력하고 **로그인**을 누른다 | "회원 로그인은 이메일로 간단히 합니다." | 로그인 후 주문서로 돌아온다 |
| 17 | 주문서에서 주문자 정보(이름·이메일·전화)를 확인한다. 비어 있으면 입력한다 | "주문자 정보를 확인합니다." | 입력 칸 |
| 18 | **주문자와 동일** 체크로 수령인을 채우고, **주소 검색**을 눌러 주소를 고른다 | "배송지는 우편번호 검색으로 찾아요." | 우편번호·기본주소가 채워진다. 상세주소에 "101호" 입력 |
| 19 | **배송 메모**에서 하나를 고른다 | "문 앞에 놓아 달라고 요청할 수도 있어요." | 선택한 메모 |
| 20 | 결제수단 **카드**를 선택한다 | "결제는 카드, 계좌이체, 토스페이를 지원합니다." | 카드 선택됨 |
| 21 | **약관**에 동의 체크한다 | "약관에 동의하고 결제를 진행합니다." | **결제하기** 버튼이 활성화된다 |
| 22 | **결제하기**를 누른다 | "여기서 토스페이먼츠 결제창이 열립니다." | **토스 결제창이 새 창으로 열린다** |
| 23 | **여기서 시연을 마친다.** 결제창을 닫는다(취소) | "실제 결제는 하지 않고 여기까지 보여 드렸습니다." | 주문서로 돌아온다. 주문은 "결제 대기" 상태로 남는다 |

**시연 끝 멘트 (30초)**: "이상으로 홈에서 카테고리, 상품 상세, 구매, 결제창까지의 흐름을 보여 드렸습니다. 작품 사진과 소개는 장인이 올리면 AI가 상세 페이지를 만들어 줍니다."

## 3. 하지 않는 것 (실제 모드에서 막히거나 시연 데이터라 설명이 필요한 것)

| 화면 | 이유 | 대응 |
|---|---|---|
| 상단 메뉴 **선물관 · 장인관 · 기획전** | 목적 화면이 없어 눌러도 반응 없음(비활성) | 누르지 않는다. 선물·장인은 **홈 섹션**으로 보여 준다 |
| 홈 **베스트** · **기획전** 영역, 목록 **인기순·판매순·찜순** | 시연용 목업 카탈로그(주방 상품 위주). 우리 상품과 다르다 | 누르거나 설명하지 않는다 |
| **쿠폰 · 적립금 · 할인코드 · 무통장입금** | 실제 모드에서 비활성 | 건드리지 않는다 |
| 소재 · 공예 · 선물 포장 **필터**, 재입고 알림, 사진 후기 필터 | 실제 모드에서 비노출/비활성 | 쓰지 않는다 |
| **옵션 선택이 필요한 상품** | 옵션 구매 미지원 | 이 문서의 상품은 모두 옵션이 없다 |
| **실제 결제 승인** | 시연 범위 아님 | 토스 결제창은 열기만 하고 닫는다 |
| 이미지가 사진이 아니라 그림 | 직접 그린 일러스트다(글자 없음) | 실제 사진이라고 말하지 않는다 |

## 4. 시연 중 문제가 생기면

| 증상 | 즉시 대응 | 원인 후보 |
|---|---|---|
| 이미지가 깨져 보인다 | 새로고침 한 번. 안 되면 다른 상품으로 넘어간다 | GitHub 이미지 서버 지연 |
| 로그인 후 다시 로그인 화면 | 한 번 더 로그인 | 시연 계정은 동시 로그인이 허용되지만, 다른 계정이면 이전 로그인이 끊긴다 |
| **구매하기** 뒤 오류 메시지 | 장바구니로 돌아가 다시 시도. 안 되면 다른 상품 | 재고·네트워크 |
| 주소 검색 창이 안 열린다 | 팝업 허용 확인. 안 되면 주소를 직접 입력 | 팝업 차단 |
| 결제창이 안 열린다 | 약관·결제수단 선택을 확인하고 다시 누른다. 안 되면 "결제창 연동은 이 단계에서 열립니다"로 설명하고 마무리 | 결제 키 설정, 팝업 차단 |
| 상품이 목록에 없다 | 최신순 정렬, 대분류를 바꿔 본다 | 배포가 덜 됨 |
