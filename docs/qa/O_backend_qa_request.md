| # | 항목 | 용도 |

| 5 | 카카오 OAuth 테스트 code 발급 방법 | OAuth 시나리오 |
| 6 | 스테이징 서버 baseUrl | 모든 테스트 |
| 7 | DB 직접 접근 권한 (선택) or 상태 조회 내부 API | DB Verification |
