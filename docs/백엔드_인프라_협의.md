## 인프라 구성

### 서버 분리 구조

```
APP 티어 (EC2)
 └─ ALB → Spring Boot (내장 톰캣)
 └─ nginx: ALB 미도입 시 리버스 프록시로 대체 (현재 우선순위 낮음)

DB 티어 (EC2 또는 RDS)
 └─ PostgreSQL 18

Redis (EC2)
 └─ 세션/캐싱 용도 (기능 확정 전까지 선택적)

Monitoring (EC2)
 └─ Prometheus + Grafana
```

### ALB / nginx 결정

- **보안팀 WAF 적용 요건**으로 ALB 필요
- ALB 도입 시 nginx 불필요, ALB에서 TLS 종료
- ALB 비용: +$16~20/월 (nginx 대체 시 $0)
- **현재 방향: ALB 도입 (WAF 연동 고려)**

### DB 배치

- RDS 또는 EC2 직접 설치 모두 수용 가능
- 비용 절감 시 EC2 직접 설치 선택
- **결정 기준: 인프라팀 스냅샷 관리 여부 + 비용**

| liveness | `/actuator/health/liveness` |
| readiness | `/actuator/health/readiness` |
| 수집 주기 | 15s |

### application.yml 설정 (인프라 요구사항)

```yaml
server:
  shutdown: graceful

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s

management:
  server:
    port: 9090
  endpoints:
    web:
      exposure:
        include: health, prometheus
  endpoint:
    health:
      probes:
        enabled: true
      show-details: when-authorized
  metrics:
    tags:
      application: ${spring.application.name}
```

### [그룹 B] ALB 헬스체크 경로

현재 `/actuator/health`는 관리 포트(9090)에만 노출되어 있고, ALB는 서비스 포트(8080)만 바라봅니다. 아래 두 방식 중 선택 필요.

| 방안 | 설명 |
|---|---|
| **A안** (인프라 처리) | ALB 헬스체크 포트를 9090으로 지정. BE 작업 없음. 인프라 SG 규칙 1개 추가 필요. |
| **B안** (BE 추가) | 8080에 `/healthz` 엔드포인트 추가 (200 OK만 반환). 관리 포트 경로 불필요. |

> K8s Liveness/Readiness Probe는 기존대로 9090 사용 — 이 항목과 무관합니다.
