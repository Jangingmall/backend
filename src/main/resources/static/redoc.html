장인몰 (미담) API (0.0.1-SNAPSHOT)

Download OpenAPI specification:

장인몰(미담)은 국가무형유산 장인의 작품을 직접 구매할 수 있는 B2C 마켓플레이스입니다. 본 문서는 장인몰 REST API의 공식 레퍼런스입니다.

Quick Start

API 연동은 3단계로 시작합니다.

1단계 — 회원가입 / 로그인

POST /api/member/signup
Content-Type: application/json

{
  "email": "buyer@example.com",
  "password": "P@ssw0rd!",
  "name": "홍길동"
}

2단계 — Access Token 발급

POST /api/member/login
Content-Type: application/json

{
  "email": "buyer@example.com",
  "password": "P@ssw0rd!"
}

응답의 accessToken을 저장합니다. Refresh Token은 Set-Cookie: refreshToken=... 으로 전달됩니다.

3단계 — 인증이 필요한 API 호출

GET /api/member/me
Authorization: Bearer {accessToken}

서버 환경 (Base URL)

환경 Base URL
Production https://midam.store
Local http://localhost:8080

인증 (Authentication)

장인몰 API는 JWT Bearer Token 방식을 사용합니다.

  • POST /api/member/login 또는 OAuth2 로그인 성공 시 accessToken 발급
  • 모든 인증 필요 API에 Authorization: Bearer {accessToken} 헤더 포함
  • Access Token 만료(401 UNAUTHORIZED) 시 POST /api/member/token/refresh 호출
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

OAuth2 소셜 로그인 (카카오 / 네이버)

  1. GET /api/member/oauth2/{provider} → 소셜 로그인 페이지 리다이렉트
  2. 인증 완료 후 프론트엔드 콜백 URL로 code 파라미터 전달
  3. POST /api/member/oauth2/exchange → accessToken 교환

공통 요청 형식

Content-Type: application/json
Accept: application/json
Authorization: Bearer {accessToken}   # 인증 필요 API

날짜/시간은 모두 ISO 8601 형식(2025-01-15T09:30:00Z)으로 주고받습니다.

공통 응답 형식

성공

{
  "success": true,
  "status": 200,
  "data": { ... }
}

실패

{
  "success": false,
  "status": 400,
  "errorCode": "INVALID_INPUT",
  "message": "입력값이 올바르지 않습니다"
}

공통 에러 코드

아래 에러 코드는 명시 여부와 무관하게 모든 엔드포인트에 공통 적용됩니다. 각 엔드포인트 응답 목록에는 해당 비즈니스 로직에 특화된 에러만 추가로 표시됩니다.

HTTP errorCode 발생 조건
400 INVALID_INPUT @Valid 필드 검증 실패
400 REQUEST_INVALID Content-Type 불일치, 타입 변환 실패
400 REQUEST_BODY_MALFORMED 파싱 불가한 요청 바디
401 UNAUTHORIZED 인증 토큰 없음 또는 만료
403 FORBIDDEN 권한 없음 (타 사용자 리소스 접근 등)
404 NOT_FOUND 리소스를 찾을 수 없음
409 CONFLICT 중복 리소스 (이메일, 찜 등)
422 BUSINESS_RULE_VIOLATION 비즈니스 규칙 위반 (상태 전이 불가 등)
429 TOO_MANY_REQUESTS 요청 횟수 초과
500 INTERNAL_ERROR 서버 내부 오류

페이지네이션

오프셋 페이지네이션

page(0-based), size(기본 20) 쿼리 파라미터로 전달합니다.

GET /api/products?page=0&size=20

{
  "content": [...],
  "totalElements": 100,
  "totalPages": 5,
  "number": 0,
  "size": 20,
  "first": true,
  "last": false
}

커서 페이지네이션

cursor(첫 요청 시 생략), size(기본 20) 쿼리 파라미터로 전달합니다.

GET /api/artisans/subscriptions?size=20
GET /api/artisans/subscriptions?cursor=eyJpZCI6MTB9&size=20

{
  "items": [...],
  "nextCursor": "eyJpZCI6MX0=",
  "hasNext": true,
  "totalCount": 100
}

hasNext가 false이면 마지막 페이지입니다. nextCursor는 불투명 Base64 토큰으로 파싱하지 말고 그대로 전달하세요.

Dev (로컬 전용)

개발용 토큰 즉시 발급

🔓 인증 불필요

🚧 local / local-postgresql 프로파일에서만 동작합니다.

회원가입·승인 없이 role을 지정해 JWT를 즉시 발급합니다. AI팀 로컬 연동 테스트용.

만료 시간: 7일 — 일반 accessToken(30분)과 달리 장기 토큰을 발급합니다. 재발급 없이 일주일간 사용 가능합니다.

발급한 토큰을 Authorization 헤더에 담아 사용합니다.

Authorization: Bearer {accessToken}
role memberId 용도
ARTISAN -1 콘텐츠 생성, 상품 등록/수정/삭제
USER -3 챗봇, 찜, 알림, 문의
ADMIN -2 관리자 기능

memberId가 음수이므로 실제 DB 회원 조회가 필요한 엔드포인트는 404가 발생할 수 있습니다.

query Parameters
role
string
Default: "ARTISAN"
Enum: "ARTISAN" "USER" "ADMIN"

상품 상태를 변경합니다. 허용 전이: DRAFT→ON_SALE|HIDDEN, ON_SALE→SOLD_OUT|HIDDEN, SOLD_OUT→ON_SALE|HIDDEN, HIDDEN→ON_SALE|DRAFT

Authorizations:
bearerAuth
path Parameters
productId
required
integer <int64>

상품 ID

Request Body schema: application/json
status
required
string

변경할 상태 (ON_SALE/SOLD_OUT/HIDDEN/DRAFT)

Responses

Production

https://midam.store/api/products/{productId}/status

Local

SSE 실시간 알림 구독

🔑 USER 이상

SSE(Server-Sent Events)로 실시간 알림을 수신합니다.

Browser EventSource는 Authorization 헤더를 설정할 수 없으므로 JWT를 쿼리 파라미터로 전달합니다.

연결 직후 connect 이벤트가 전송되고, 이후 알림 발생 시 notification 이벤트가 전송됩니다.

Authorizations:
bearerAuth
query Parameters
token
string

JWT 액세스 토큰 (EventSource 사용 시 필수)

Responses

Production

https://midam.store/api/notifications/stream

Local

http://localhost:8080/api/notifications/stream
